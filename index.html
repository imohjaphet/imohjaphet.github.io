featured build · Zapier + Airtable

Ambassador Commission Automation

A capstone build for Cybervast AI Automation's referral program: three connected Zaps that take a referral from a single Google Form submission all the way to a confirmed, correctly-calculated commission — with zero manual steps in between.

All three Zaps read and write the same Airtable base, so it stays the single source of truth across the whole referral lifecycle.

before

Referrals tracked across scattered WhatsApp chats and email threads. Admins calculated each ambassador's 20% commission by hand every month — slowly, and with frequent disputes. Nobody was notified when the ₦20,000 acceptance fee actually landed.

after

Every referral is logged to one Airtable CRM the moment the form is submitted. Commission is calculated by an Airtable formula, never by hand. Marking a fee "Paid" notifies the ambassador within two minutes, and monthly reports send themselves.

Key decision — the 20% commission formula lives in Airtable, not inside the Zap logic, so one formula edit updates every record at once — and supports moving to tiered rates later without touching a single Zap.

about

I like systems that keep working when nobody's watching.

I build automation on n8n because it handles real branching logic and custom code where the no-code nodes run out. I'm currently running it self-hosted, with an AI assistant wired in through OpenRouter for the steps that benefit from a model's judgment.

I care less about a workflow looking impressive on a good day, and more about what it does on a bad one — a failed API call, a malformed input, a message that doesn't fit the expected shape.
